This program is a simple inventory management system built in C++ for tracking supply items used during small-dog meetup events.

It allows the user to:

- Enter 5 custom inventory items
- Set quantities for each
- Print the current inventory
- Search for a specific item
- Save the inventory to a file (meetup_inventory.txt)
- Load and display saved inventory from the file

The project demonstrates object-oriented design, file handling, input validation, and basic searching.
