This program reads a medical drug dataset from a CSV file and extracts key information for analysis.

The program:

- Loads patient treatment data from real_drug_dataset.csv
- Extracts Patient ID, Age, Drug Name, Dosage (mg), and Improvement Score
- Displays each patient record
- Generates a graph showing the distribution of Improvement Scores
- Prints summary statistics (averages + total records)

This project demonstrates file I/O, classes, vectors, data parsing, validation, and basic data visualization in C++.
