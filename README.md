This program demonstrates basic inheritance and method overriding in C++. It creates a class hierarchy with three roles: User, Employee, and InventoryManager. Each class overrides the accessLevel() method to display a different access message. In main(), an InventoryManager object is created and its overridden method is called, showing how derived classes replace parent behavior. The program’s purpose is to illustrate how access control can be represented using class hierarchies and polymorphism.
