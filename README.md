Earthquake Supplies Bag Program
What it does?
Keeps track of what’s inside your emergency “go bag.”
Saves the list of supplies into items.txt so you can always review or update it.
Loads and displays the list, reminding you if you’re missing anything important.

How the class fits
Item.name → supply name (e.g., “Water bottles”, “Flashlight”, “First aid kit”).
Item.quantity → how many units you’ve packed.
saveToFile() → writes the supply and count to the file.
loadFromFile() → displays the current earthquake bag contents.
